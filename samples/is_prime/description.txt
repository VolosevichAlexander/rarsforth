Проверка на простоту.

PRIME? возвращает 1 для простого числа и 0 для составного. Стратегия:
отфильтровать 0, 1, 2 и чётные; обработать 3, 5, 7 напрямую; для нечётного
n >= 9 проверить нечётные делители 3, 5, 7, ..., до n/2. Аккумулятор
(1 = всё ещё простое) лежит под n; если делитель найден, аккумулятор
переписывается на 0 и LEAVE взводит выход на ближайшем +LOOP.

Демонстрирует: цепочки ранних выходов через EXIT в IF, DO с +LOOP шагом 2,
LEAVE для досрочного завершения, паттерн аккумулятора под переменной цикла.

Скрипт проверяет несколько небольших чисел: простые, чётные и нечётные
составные.
