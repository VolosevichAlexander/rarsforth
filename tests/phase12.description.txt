Фаза 12: исправления для строгого соответствия стандарту.

Проверяет:
- `'` на VARIABLE возвращает её PFA; последующий `@` читает сохранённое значение (1).
- `'` на колон-определении возвращает его PFA; EXECUTE сканирует словарь и диспетчеризует нужное слово (2).
- CONSTANT теперь хранит значение в ячейке PFA; `' C1 @` возвращает 123 (3).
- Несколько констант через tick и EXECUTE: 1 плюс 2 равно 3 (4).
- `' VAR EXECUTE` даёт тот же эффект, что просто вызов VAR; затем `@` читает значение (5).
- Два 30-символьных имени, отличающиеся последним символом, существуют как отдельные записи в словаре (6-9).
- FIND для каждого длинного имени возвращает разные id, поэтому `=` между ними даёт 0 (10).
- SAVE-BUFFERS пишет файл на диск (11).
