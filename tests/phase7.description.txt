Фаза 7: определяющие слова.

Проверяет:
- CREATE создаёт слово, кладущее свой PFA. После CREATE A1 три вызова `,` заполняют три ячейки; A1 + offset @ читает каждую (1).
- CREATE плюс DOES> для CONST: 42 CONST ANS, затем ANS кладёт 42 (2).
- Тот же CONST переиспользуется для ONE и TWO; сложение работает (3).
- ARR2: CREATE плюс DOES> с телом SWAP 2 * + @ реализует двухэлементный массив (4-6).
- COMPILE откладывает компиляцию. STAR с IMMEDIATE на этапе компиляции кладёт следующий токен в вызывающее колон-определение (7-9).
- [COMPILE] форсирует компиляцию immediate-слова; MYIF оборачивает IF (10-12).
- FORGET удаляет слово и всё созданное после него; ABC остаётся, DEF и GHI удалены (13-17).
- VARIABLE выделяет ровно 2 байта; две подряд идущие VARIABLE отличаются на 2 (18).
