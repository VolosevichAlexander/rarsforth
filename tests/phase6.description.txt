Фаза 6: слова текстового интерпретатора.

Проверяет:
- WORD с пробелом-разделителем читает следующий токен и возвращает счётную строку (1-2).
- WORD кладёт настоящую длину в count-байт (3).
- FIND возвращает ненулевой compilation address для существующего слова (4), 0 для отсутствующего (5).
- Цикл FIND + EXECUTE для DUP (6).
- >IN отслеживает позицию парсинга; чтение `>IN @` отражает позицию уже после этих токенов (7).
- ABORT чистит оба стека и прерывает остаток строки; последующие строки видят пустой стек (8-9).
- QUIT чистит только return-стек и прерывает; data-стек сохраняется (10-11).
- QUERY читает следующую строку stdin в TIB, дальнейшие токены берутся оттуда (12).
- EXPECT читает строку stdin в буфер по адресу (14, при этом HELLO из строки 15 потребляется).
