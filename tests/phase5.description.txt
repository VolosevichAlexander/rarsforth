Фаза 5: операции с памятью и строками.

Проверяет:
- CMOVE копирует n байт из src в dst (1).
- MOVE копирует n 16-битных ячеек (2).
- FILL заполняет n байт заданным байтом (3) и является no-op при n=0 или n<0 (4, 12-13).
- COUNT извлекает (addr+1, длина) из счётной строки, далее TYPE печатает её (5).
- TYPE печатает n байт; при n=0 не делает ничего (6-7).
- -TRAILING обрезает trailing-пробелы (8), сводит счётчик к нулю для строки из одних пробелов (9), оставляет длину неизменной если trailing-пробелов нет (10).
- Сводный pipeline: счётная строка с trailing-пробелами, COUNT + -TRAILING + TYPE (11).
