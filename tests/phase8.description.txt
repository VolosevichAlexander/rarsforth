Фаза 8: pictured numeric output и ядро двойных чисел.

Проверяет:
- D+ на одноячеечных doubles: 1+2, 65536+65536 (1-2).
- D+ с DNEGATE: -1 + 1 = 0 (3).
- DNEGATE для 0, 1, 100 (4-6).
- D< при сравнении doubles разных знаков (7-9).
- <# #S #> TYPE печатает double в текущей BASE (10).
- <# #S #> для нуля даёт одиночный '0' (11).
- Явный `#` повторяется столько раз, сколько цифр (13).
- PRN: классическое колон-определение DUP ABS 0 <# #S ROT SIGN #> TYPE; тесты на отрицательное, ноль, положительное (14-15).
- HOLD вставляет произвольные символы в обратном порядке; вывод читается слева направо (16).
- CONVERT парсит цифры начиная с addr+1, накапливает в double, останавливается на первом не-цифре (18).
- CONVERT без цифр в addr+1 оставляет исходный double без изменений (19).
