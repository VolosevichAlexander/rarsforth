Фаза 4: поток управления.

Проверяет:
- EXIT внутри колон-определения пропускает остаток тела (1).
- Условный EXIT через IF, ветви true и false (2-3).
- SAFE-DIV: EXIT внутри IF как защита от деления на 0 (4).
- EXIT во вложенном слове не разматывает внешнего вызывающего (5).
- +LOOP с положительным шагом (6) и отрицательным шагом (7).
- +LOOP с шагом 3 (8).
- LEAVE заставляет цикл завершиться на ближайшей границе LOOP (9-10), код после LEAVE в той же итерации всё ещё выполняется.
- J возвращает индекс внешнего цикла во вложенном DO LOOP (11).
- BEGIN WHILE REPEAT обратный счёт, нулевой проход, цикл квадратов (12-14).
- EXIT на верхнем уровне молча игнорируется: `EXIT 42 .` всё равно печатает 42 (15).
