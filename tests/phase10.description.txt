Фаза 10: mass storage.

Проверяет:
- BLK начинается с 0 (что означает ввод с терминала) (1).
- BLOCK возвращает рабочий адрес; байт сохраняется и читается обратно (2).
- Адрес BLOCK стабилен между повторными вызовами (3).
- Блоки разнесены ровно на 1024 байта (4).
- BUFFER работает так же как BLOCK в этой in-memory модели (5).
- UPDATE и EMPTY-BUFFERS отрабатывают, не меняя содержимое байтов (6).
- SAVE-BUFFERS не возвращает ошибку (7).
- Начальное значение SCR равно 0 (8). После LIST n значение SCR = n (9).
- LIST печатает 16 строк по 64 символа (9, здесь в основном пробелы).
- LOAD интерпретирует содержимое блока как исходник; блок заполнен байтами "2 3 + ." и LOAD заставляет их свернуться в 5 (10).
- Ошибочные случаи: номера блоков вне диапазона печатают BLOCK err и кладут 0 (11).
